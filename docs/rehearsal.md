# Classroom Rehearsal Checklist

## Before Class

- Build the project with `cjc -p src --output-dir target\manual`.
- Run `target\manual\main.exe self-check`.
- Open `docs/dashboard.html` in a browser if a visual page is needed.
- Keep `docs/command_sheet.md` open as the command checklist.

## Live Demo

1. Show `version` and `summary`.
2. Show knowledge distribution with `source-map`.
3. Show operation logic with `trace match`.
4. Answer a syntax question with `ask match`.
5. Show LLM preparation with `llm-request match`.
6. Show final readiness with `final-check`.

## Backup Plan

- If GitHub push fails, explain that local commits are ready and use `git push` when the network is available.
- If a browser is unavailable, use `dashboard` and `final-check` CLI output instead of the HTML page.
