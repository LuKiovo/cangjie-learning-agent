Main workflow

Import or add local knowledge, retrieve matched sources, generate source-backed answers, and export review artifacts for classroom acceptance.

target\manual\main.exe ask match
target\manual\main.exe card ArrayList
target\manual\main.exe export-answer match_answer match
target\manual\main.exe llm-request match

Knowledge

Official/course notes, syntax notes, examples, and error notes are scanned recursively from local files.

Retrieval

Full query matches receive higher scores, and word-level fallback keeps multi-word questions useful.

LLM-ready

Prompt and request drafts include local context and source paths before a future HTTP transport is connected.

Acceptance

Reports, indexes, source maps, sessions, and study cards can be exported for teacher review.
