# Teacher Summary

This project is a Cangjie Learning Agent for beginners. It is implemented with Cangjie source files and uses a local `.md/.txt` knowledge base for source-backed syntax help.

## What It Demonstrates

- Local official/course knowledge and personalized notes.
- Retrieval, source scoring, primary source selection, and source context display.
- Syntax answer, example, practice, quiz, study card, and learning session generation.
- LLM request draft construction without storing API keys.
- Static HTML dashboard and Markdown delivery artifacts generated by Cangjie.

## Current Knowledge Base

- Official/course files: 6
- User knowledge files: 8

## Suggested Review Commands

```powershell
target\manual\main.exe self-check
target\manual\main.exe trace match
target\manual\main.exe ask match
target\manual\main.exe llm-request match
target\manual\main.exe export-dashboard dashboard
```
