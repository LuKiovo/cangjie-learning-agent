# Cangjie Learning Agent Roadmap

## Completed Core

- Local .md/.txt knowledge import and add commands.
- Source-backed retrieval, scoring, primary source selection, and source context display.
- Beginner answer, example, practice, quiz, study card, and learning session commands.
- LLM request draft workflow and local response archive.
- Static dashboard, final check, trace, and export reports generated by Cangjie.

## Remaining Work

1. Confirm the available Cangjie HTTP package or stdx HTTP capability.
2. Connect `llm-request` payloads to a real HTTPS POST request.
3. Parse the LLM response and save it through the existing response archive.
4. Optionally make the static dashboard interactive or wrap the CLI in a desktop shell.
5. Convert more teacher PDF content into .md/.txt notes for richer local retrieval.

## Recommended Demo Order

1. `self-check`
2. `source-map`

4. `ask match`
5. `llm-request match`
