# HCCDA Cangjie Beginner Course Index

This local index summarizes the teacher slide topics so the agent can retrieve course-aligned Cangjie learning material.

## 01 Identifiers, Basic Data Types, Console IO

Topics: Cangjie overview, identifier rules, naming style, integer types, floating point types, Bool, Rune, String, tuple, Array, Range, Unit, Nothing, console input and output.

## 02 Variables and Basic Expressions

Topics: Cangjie program structure, variable definition, `let`, `var`, assignment, arithmetic expressions, comparison expressions, logical expressions, type conversion.

## 03 Conditions and Loops

Topics: `if` expressions, loop structures, `while`, `do while`, `for in`, `match` expressions, enum types.

## 04 Collection Types

Topics: Collection overview, common Collection types, `ArrayList`, `HashMap`, Iterable, Collections utility usage.

## 05 Functions and Object-Oriented Basics

Topics: function definition and calls, function parameters, return values, function body, function type, class, object, constructor, static members, member variables, member functions, properties, access modifiers.

## 06 Food Ordering System Case

Topics: project requirement design, layered architecture, model layer, service layer, view layer, terminal interaction, Collection-based data storage, menu flow, `match`-based command dispatch.
