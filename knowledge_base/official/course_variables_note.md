# Cangjie Variables And Basic Expressions

Topic keywords: Cangjie variable definition, let, var, assignment, expression, type conversion.

Beginner note:

- Use `let` for values that should not be reassigned.
- Use `var` for values that need to change later.
- Keep variable names clear and close to the course naming style.
- Basic expressions include arithmetic, comparison, logical operations, and type conversion.

Tiny example:

```cangjie
main(): Int64 {
    let name = "Cangjie"
    var count = 1
    count = count + 1
    println(name)
    println(count)
    return 0
}
```
