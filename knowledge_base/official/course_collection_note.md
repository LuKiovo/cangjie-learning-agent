# Cangjie Collection Types

Topic keywords: Cangjie Collection, ArrayList, HashMap, Iterable, Collections utility.

Beginner note:

- Collection types store multiple values and are useful in menu, list, and table-like programs.
- `ArrayList` is useful when values are ordered and the program needs list-style access.
- `HashMap` is useful when values should be found by key.
- Course projects can use collections to store menu items, user choices, and simple records.

Tiny example idea:

```cangjie
main(): Int64 {
    println("Use ArrayList for ordered values.")
    println("Use HashMap for key-value lookup.")
    return 0
}
```
